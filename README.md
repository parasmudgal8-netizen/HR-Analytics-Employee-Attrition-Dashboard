# HR Analytics Employee Attrition Dashboard

## 📌 Project Overview

This project presents an interactive HR Analytics Dashboard built using Microsoft Power BI. The dashboard helps HR teams analyze employee attrition, monitor workforce trends, and identify the major factors contributing to employee turnover.

The dashboard enables users to filter data dynamically and gain actionable insights for better workforce planning and retention strategies.

---

## 🎯 Problem Statement

Organizations often struggle to understand why employees leave the company. The objective of this project is to analyze employee data to identify the key factors affecting attrition and support HR decision-making through an interactive dashboard.

## 📈 Key Performance Indicators (KPIs)

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Retention Rate
- Average Monthly Income

---

## 📊 Dashboard Analysis

The dashboard provides analysis based on:

- Department
- Job Role
- Gender
- Age Group
- Salary Slab
- Overtime
- Education Field
- Job Satisfaction

Interactive slicers allow users to filter the dashboard dynamically.

---

## 💡 Business Insights

- Employees working overtime show higher attrition.
- Lower salary slabs experience higher employee turnover.
- Certain departments have noticeably higher attrition than others.
- Job satisfaction is an important factor influencing attrition.
- Attrition varies across different age groups and job roles.
